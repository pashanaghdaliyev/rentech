Bilik Mərkəzi

Təməl anlayışlardan sistem seçiminə qədər aydın öyrənmə yolu.

    Quraşdırılmış sistemin texniki xidməti

    Sistem satmırıq və quraşdırmırıq. İşləyən sistemin nə qədər itirdiyini ölçür, səbəbini tapır və aradan qaldırırıq.

    Günəş sistemi xarab olanda dayanmır — sakitcə az verir. Çirklənmiş panel, kölgə, isti nöqtə, qopmuş string birləşməsi və ya invertərin səhv parametri: işıq gəlir, sahib isə hər ay itirdiyi enerjidən xəbərsiz qalır.

    Quraşdıran şirkətlərin çoxu satdığı sistemi sonradan müşayiət etmir. Zəmanət sənədləri natamam olur, nasazlıq çıxanda isə kimə müraciət edəcəyi bilinmir.

    Bizim işimiz burada başlayır: ölçürük, sənədləşdiririk, düzəldirik.

    Xidmətlər

    • Texniki baxış və diaqnostikaSistemin real istehsalını gözlənilən istehsalla müqayisə edirik, string və invertər ölçmələri aparırıq, itkinin mənbəyini tapırıq.
    • Termal baxışTermal kamera ilə panellərdə isti nöqtələr, zədələnmiş hüceyrə və birləşmə qüsurları aşkarlanır — gözlə görünməyən nasazlıqlar.
    • İnverter və elektrik nasazlıqlarıXəta kodlarının oxunması, parametrlərin yoxlanılması, qoruma və torpaqlama sisteminin nəzarəti.
    • Panellərin təmizlənməsiPanelə zərər verməyən üsulla. Təmizlikdən əvvəl və sonra istehsal ölçülür — fərq rəqəmlə göstərilir.
    • Zəmanət tələbinin sənədləşdirilməsiNasazlıq zəmanət altındadırsa, istehsalçıya və ya quraşdırıcıya təqdim etmək üçün lazım olan texniki sənədi hazırlayırıq.
    • İllik texniki xidmət müqaviləsiİldə iki planlı baxış, təcili çağırışa üstün növbə və hər baxışdan sonra yazılı hesabat.

    Hesabatda nə olur

    • Ölçmə nəticələri: string gərginliyi, cərəyan, invertər göstəriciləri
    • Termal şəkillər və üzərində işarələnmiş problemli sahələr
    • Gözlənilən və real istehsalın müqayisəsi — itki faizlə
    • Tapılan nasazlıqların siyahısı və təcililik dərəcəsi
    • Tövsiyələr: nə indi, nə sonra, nə isə zəmanət hesabına
