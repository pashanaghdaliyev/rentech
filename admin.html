RenTech admin

Admin token daxil et

Xəbərləri təsdiqləmək üçün admin token lazımdır. Token bu telefondan çıxmır — yalnız localStorage-da saxlanılır.

  1. Cloudflare dashboard → rentech Pages layihəsi → Settings → Environment variables
  2. Ora əlavə etdiyin ADMIN_TOKEN dəyəri aşağıya yapışdırılır
  3. Token uzun random sətirdir (məs. 32+ hərf/rəqəm). İtirsən, dashboard-dan yenidən oxumaq/dəyişmək olar.
